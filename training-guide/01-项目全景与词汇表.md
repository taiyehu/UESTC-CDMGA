# 项目全景与词汇表

## 技术栈

| 层次 | 本项目实际使用 | 用途 |
|---|---|---|
| 当前前端主线 | React 19、TypeScript 7、Vite 8 | 浏览器页面与交互，工程位于 `reactproject/` |
| 前端组件/样式 | React 组件、CSS、自定义主题变量 | 表单、弹窗、布局与主题 |
| 前端辅助 | React Router、Axios、Playwright | 路由、请求和浏览器自动化 |
| 旧版前端 | Vue 3、Vite 7、Element Plus | `vueproject/` 保留旧实现，不是当前部署主线 |
| 前端构建环境 | Node.js 24、pnpm 10.30.0 | 运行 Vite、安装依赖、构建 `dist` |
| 后端 | Java 25、Spring Boot 3.5.3、Maven Wrapper 3.9.10 | HTTP API 与业务逻辑；Maven 负责构建 |
| 数据层 | Spring Data JPA/Hibernate、MySQL 8 系 | 数据读写与表映射；MySQL 具体小版本未在仓库锁定 |
| 部署 | GitHub Actions 使用 Ubuntu 22.04；Nginx、systemd 版本未锁定 | 托管、守护与自动发布 |

注意：`pom.xml` 同时显式声明 Spring Security 3.3.4，而 Spring Boot 父版本是 3.5.3，并有重复依赖。后续维护宜移除显式版本和重复项，让 Boot 统一管理兼容版本。

版本依据：`reactproject/package.json`、`reactproject/pnpm-lock.yaml`、`webpage/pom.xml`、`webpage/.mvn/wrapper/maven-wrapper.properties` 和 `.github/workflows/`。`^`/`~` 是允许范围，不等于每台电脑实际安装的小版本；前端安装应遵守锁文件。

## 一次请求如何流动

以“前端查询课题”为例：页面调用 `reactproject/src/api.ts` → Axios 请求 `/api/course/...` → 开发时 Vite 把请求代理到 `localhost:8080`，生产时 Nginx 代理 → `CourseController` 接收 → `CourseService` 处理 → `CourseRepository` 访问 MySQL → JSON 原路返回页面。

排错时从这条链逐段确认，不要一次修改多层。

## 主要业务模块

- `identity`：账户、密码、角色和逻辑删除。
- `profile`：头像、简介、称号与审核状态。
- `course`：课题主体，类别包括普通、比赛、Bingo、排名等。
- `issue`：课题内部的题目、歌曲、图片与文件。
- `score`：用户提交、审核、得分、备注与排名数据。
- `activity` + `activity_course_assoc`：活动及其关联课题。
- `rank_config`：排名计分配置。
- `team` + `bingo_tips`：Bingo 队伍、格子状态和提示。

后端 API 主要前缀是 `/api/identity`、`/api/profile`、`/api/course`、`/api/issue`、`/api/score`、`/api/activity`、`/api/rank`、`/api/team` 和 `/api/bingo-tip`。

## 新人必须认识的词

- 终端：输入命令的窗口（PowerShell、Terminal）。
- 当前目录：命令正在操作的文件夹；先用 `pwd` 确认。
- 依赖：项目借用的第三方代码；前端由 pnpm 管理，后端由 Maven 管理。
- 构建：把源代码检查并转成可部署产物；前端是 `dist/`，后端是 `target/*.jar`。
- API：前端与后端约定的请求地址、参数和返回格式。
- 端口：同一电脑上区分服务的号码；当前 React 前端为 5174、旧版 Vue 前端为 8081、后端为 8080。
- 环境/Profile：开发和生产的不同配置；Maven 的 `dev` 默认激活，打生产包使用 `-P prod`。
- CORS：浏览器对跨来源请求的限制；开发环境由后端允许 8081，生产由 Nginx 同源代理。
- ORM/JPA：用 Java Entity 映射数据库表。
- CI/CD：推送代码后由 GitHub Actions 自动构建和部署。
- 日志：程序运行记录；报错时最重要的证据。
